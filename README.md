My concept of this site is to have a colorful nature scene where you can decorate it with illustrations of critters such as a frog, butterfly, ladybug, and dragonfly. You can resize each critter by selecting it and pressing the up and down arrows. You can move them by dragging them with your mouse or trackpad. Each critter has its own animation that mimicks how it actually moves in real life! Animations are done with javascript/gsap. All assets are illustrated by me, using Adobe Illustrator!
